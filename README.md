## 页面模板

| 路由 | 说明 |
|------|------|
| `/` | 首页 — Hero 展示 + 文章列表 |
| `/archives` | 文章归档 |
| `/categories` | 分类总览 |
| `/tags` | 3D 标签云 |
| `/links` | 友链展示 & 自助提交/修改 |
| `/photos` | 图库（需图库插件） |
| `/moments` | 瞬间动态（需瞬间插件） |
| `/docs` | 文档项目（需文档插件） |
| `/friends` | 朋友圈（需朋友圈插件） |
| `/steam` | Steam 游戏库（需 Steam 插件） |
| `/about` | 关于页面 |
| `/projects` | 项目展示 |
| `/message` | 留言板 |

## 功能特性

- **导航** — 固定顶部毛玻璃导航，多级菜单，主题/语言切换
- **Hero** — 首页大图/视频/双图擦除/视频+双图擦除多模式，可配置标题与副标题
- **文章页** — 左侧 TOC 目录，右侧作者卡片，上一篇/下一篇，打字机摘要动画，过时文章提示
- **标签云** — 3D 立体旋转，可交互操作
- **友链** — 分组展示、信息复制、随机穿梭、自助提交/修改（需 LinksSubmit 插件）
- **归档** — 按年/月分组展示
- **国际化** — 简体中文、English、日本語、한국어，客户端切换持久化
- **亮暗切换** — 支持跟随系统偏好
- **响应式** — 桌面与移动端适配
- **后台设置** — 首页大图、页脚信息、文章设置、各插件独立配置组

## 插件支持

安装对应插件后自动启用专属模板：

| 页面 | 插件 |
|------|------|
| 图库 | 图库插件 |
| 瞬间 | 瞬间插件 |
| 文档 | 文档插件 |
| 朋友圈 | 朋友圈插件 |
| Steam | Steam 插件 |
| 友链 | 友链插件 |
| 友链自助提交/修改 | LinksSubmit 插件 |

## 快速开始

1. 在 Halo 后台主题管理界面上传并安装本主题
2. 进入主题设置页面，按需配置各项参数
3. 推荐安装对应插件以获得完整体验
